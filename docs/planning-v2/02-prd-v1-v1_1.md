# 02 - PRD (V1 and V1.1)

## V1 - Clinical ROM Capture + Note Output

## User stories
1. As a clinician, I want a guided ROM workflow so I can collect measurements quickly without manual goniometer handling.
2. As a clinician, I want clear confidence indicators so I know when to trust or retake measurements.
3. As a clinician, I want an editable note output so I can paste findings into my existing clinical notes.
4. As a clinic admin, I want patient/session history so I can compare ROM across visits.

## Functional requirements
- Session creation with patient metadata (minimal PHI required)
- Joint/movement selection templates
- Camera setup wizard with lighting/distance checks
- Real-time pose capture and joint-angle computation
- Confidence threshold gating and retake prompts
- Note generation with structured format:
  - Joint
  - Movement
  - Measured ROM
  - Confidence / data quality flag
  - Optional clinician comment
- Export options: copy-to-clipboard, PDF, structured JSON
- Session history and comparison chart (basic)

## Acceptance criteria (V1)
- End-to-end exam for core joints in under 8 minutes for trained user
- Measurement saved with timestamp and quality metadata
- Generated note can be copied in one action
- All sensitive data encrypted in transit and at rest

## V1.1 - Summary + Patient Self-Assessment

## Additional user stories
1. As a clinician, I want concise exam summaries generated from captured findings.
2. As a patient, I want guided instructions so I can perform simple ROM checks without clinician presence.
3. As a clinician, I want to review patient-run sessions before accepting results.

## Functional requirements (V1.1)
- AI summary generator for exam narrative
- Patient mode with movement prompts and safety warnings
- Session quality scoring with reject/retry state
- Clinician approval queue
- Differential rules: passive/active/resisted test flags

## Non-functional requirements
- P95 interaction latency under 200 ms for UI actions
- Stable 24+ FPS pose processing on target hardware class
- Audit trail for edits and approvals
- High availability target for production service (to be finalized)

## Data outputs
- Structured measurement record
- Human-readable note
- Optional summary paragraph
- Session-level quality report
