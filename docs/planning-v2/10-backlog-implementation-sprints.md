# 10 - Prioritized Backlog and Sprint Plan

## Epic 1: Platform Foundations
- Setup monorepo + package boundaries
- CI pipeline with lint, test, security scanning
- Auth/RBAC baseline
- Environment and secrets bootstrap

## Epic 2: ROM Capture Experience (V1)
- Camera setup wizard
- Joint template selector
- Real-time angle overlay and quality cues
- Session controls and retries

## Epic 3: Clinical Documentation
- Note block generation engine
- Editable review UI
- Copy/export actions
- Basic session history view

## Epic 4: Reliability and Compliance
- Audit logging
- Data retention controls
- Security hardening checklist completion
- Incident and backup runbooks

## Epic 5: Pilot Enablement
- Clinic onboarding guide
- Admin setup flow
- Monitoring dashboard
- Feedback loop process

## Epic 6: V1.1 Enhancements
- AI exam summarization
- Patient guided workflow
- Clinician approval queue
- Quality score improvements

## Suggested sprint sequence (2-week cadence)
- Sprint 0: foundation and architecture lock
- Sprint 1: core API + capture skeleton
- Sprint 2: measurement + note generation MVP
- Sprint 3: hardening + validation + pilot prep
- Sprint 4+: V1.1 features and optimization

## Backlog governance
- Keep WIP limits strict per agent stream
- Prioritize risks early (security, accuracy, legal claims)
- Re-evaluate scope at every sprint review
